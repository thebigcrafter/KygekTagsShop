# Agent guidance

Use the [AxolotlBucketLabs skill](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/SKILL.md) for Axolotl-PM and PocketMine-MP plugin work. Read its [writing style](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/references/writing-style.md) before writing human-facing text.

Write natural, complete sentences. Avoid em dash and en dash punctuation, semicolons in prose, and unnecessary `Label: content` phrasing. Use Markdown inline code for technical names and paths.
